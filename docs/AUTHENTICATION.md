# دخول المشرفين

## ما تم تنفيذه
- جدول حسابات المشرفين `admin_users`.
- جدول الأدوار `roles` وعلاقة متعدد إلى متعدد `user_roles`.
- تخزين كلمات المرور باستخدام Argon2 عبر pwdlib.
- إصدار JWT قصير العمر.
- `POST /api/v1/auth/login` لتسجيل الدخول.
- `GET /api/v1/auth/me` لعرض هوية المستخدم الحالي.
- الحسابات المعطلة لا تستطيع تسجيل الدخول.

## إنشاء أول مدير
بعد تشغيل الخدمات وترحيل قاعدة البيانات، أنشئ أول حساب من داخل حاوية API:

```bash
docker compose exec api python -m app.scripts.create_admin --username admin --display-name "مدير النظام"
```

سيطلب منك كلمة المرور مرتين بصورة مخفية. يجب أن تكون 12 حرفاً على الأقل. لا توجد كلمة مرور افتراضية ولا يتم إنشاء حساب مدير تلقائياً.

## تسجيل الدخول
أرسل JSON إلى `POST /api/v1/auth/login`:

```json
{
  "username": "admin",
  "password": "ضع كلمة المرور التي أنشأتها"
}
```

استخدم قيمة `access_token` في ترويسة الطلبات المحمية:

```
Authorization: Bearer <access_token>
```

## متغيرات الأمان
- `APP_SECRET_KEY`: مفتاح خاص لا يقل عن 32 حرفاً، ويجب تغييره إلى قيمة عشوائية قوية قبل التشغيل.
- `JWT_ACCESS_TOKEN_MINUTES`: مدة صلاحية رمز الدخول بالدقائق، الافتراضي 30.

## ما لم يكتمل بعد
- إدارة المشرفين والأدوار من الواجهة.
- صلاحيات دقيقة لكل وحدة وعملية.
- تحديد معدل محاولات الدخول وقفل مؤقت عند المحاولات المتكررة.
- تدوير وإبطال الرموز وتسجيل أحداث التدقيق.
- لا تفتح API على الإنترنت أو تربطه براوترات إنتاج قبل إكمال هذه الحماية.
